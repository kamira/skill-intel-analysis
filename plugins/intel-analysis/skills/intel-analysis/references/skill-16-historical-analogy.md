# SKILL-16|Historical analogy, structured comparison

> 語言 / Language: [繁體中文](skill-16-historical-analogy.zh-tw.md) · **English**

## Overview
Use historical analogy properly through a structured method — list similarities and differences
systematically, avoid forcing past experience onto the present, and still extract the analytic
value history holds.

## Framework position
**Extension module**|Tightly integrated with the historical-analogy trap guard in SKILL-07 (decision preferences)

## Core question
> Which historical case is this structurally similar to? What are the similarities and differences,
> and how do the differences change the likely outcome?

## Governing principle
> **The value of a historical analogy is in structural comparison, not surface resemblance.**
> Applying history directly ("this is just like last time") is a trap; refusing to use it at all
> ("every case is different") is waste. The correct method is controlled comparison: use
> structural similarities to generate hypotheses, and key differences to correct them.

## Procedure

**1. Select candidate analogies**: list one to three historical cases that may be structurally similar
**2. Establish the dimensions**: define which structural dimensions to compare on (actors, interests, constraints, capability, time pressure, and so on)
**3. Map systematically**: mark similarity and difference dimension by dimension
**4. Assess the effect of the differences**: how the key differences change the likely outcome
**5. Extract the analytic leads**: what history offers to the present analysis

## Dimension checklist

| Dimension | What is compared |
|-----------|------------------|
| **Actor structure** | Number and type of parties, relative strength |
| **Interest structure** | Whether the parties' core interests are comparable |
| **Constraint structure** | Capability, resources, political authorisation, international environment |
| **Time pressure** | Whether a comparable window is closing |
| **Information environment** | Intelligence quality, degree of publicity, intensity of information operations |
| **International context** | Great-power alignment, alliance structure |
| **Technological environment** | Weapon systems, communications, economic instruments |
| **Domestic politics** | Electoral cycle, public opinion, factional dynamics |

## Structured analogy template

```
Current case: []
Candidate analogy: [historical case, year]

[STRUCTURAL COMPARISON]
Dimension 1 [actor structure]:
  Similar: []
  Different: []
  Effect of the difference: [how it changes the likely outcome]

Dimension 2 [interest structure]:
  Similar: []
  Different: []
  Effect of the difference: []

Dimension 3 [constraint structure]:
  Similar: []
  Different: []
  Effect of the difference: []

(continue as needed)

[HOW THE HISTORICAL CASE ACTUALLY ENDED]
Outcome: [how it resolved]
Turning point: [what determined the outcome]

[ANALYTIC LEADS FROM THE ANALOGY]
Judgments that transfer: []
Judgments that do not transfer, and why: []
Unexpected paths worth watching: [developments that occurred historically but were not foreseen at the time]

[ANALOGY CREDIBILITY]
Overall similarity: [high/medium/low]
Largest difference: []
Is that difference enough to break the analogy: [yes/no]
```

## Output format

```
Current case: []  Analogy: []
Overall similarity: [high/medium/low]
Core similarities: []
Key differences: []  Effect: []
Transfers: []
Does not transfer: []
Feeds back to: [SKILL-XX]
```

## Cautions
- ⚠️ **Surface resemblance is not structural similarity** — "both are Middle East conflicts" is not a valid analogy
- ⚠️ The analysis of differences must be **at least as detailed as** the analysis of similarities, or confirmation bias takes over
- ⚠️ A case can have several candidate analogies; do not settle for the most intuitive one
- ✅ Feed the leads back to SKILL-07 (correcting the historical-analogy trap) and SKILL-09 (scenario forecasting)
- 💡 The "unexpected paths" in history are often the most analytically valuable — the developments nobody else saw coming either
