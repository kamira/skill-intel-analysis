# SKILL-07|Decision preferences & probability adjustment

> 語言 / Language: [繁體中文](skill-07-decision-preference.zh-tw.md) · **English**

## Overview
From every card that can be played, converge on the one most likely to be played and label its
probability, working through four factor classes: decision preference, cognitive bias,
organisational inertia and domestic politics.

## Framework position
**Step 6**|Ten-step analytic framework

## Core question
> From every card that can be played (SKILL-05), converge on the one most likely to be played.

## Governing principle
> **Layer two: the decision and cognition layer** — a decision-maker's cognitive biases,
> historical inertia and political pressures do not change which cards are on the board, but they
> do **amplify or suppress the probability that each card is chosen**.

## Procedure
**1. Assemble the available-options list**: take the screened board from SKILL-05
**2. Assess the four factor classes option by option**: check historical preference, cognitive bias, organisational inertia and domestic politics for each
**3. Attach a probability label**: combining the four classes, mark each option high / medium / low / very low
**4. Produce the probability-adjusted list**: input to SKILL-09 scenario forecasting

## The four adjustment factor classes

### 1. Decision preference and historical pattern
- What has this person or organisation done in comparable situations before?
- Is there a clear decision style (aggressive / cautious / temporising)?

### 2. Cognitive bias

| Bias | What it is | How to spot it |
|------|-----------|----------------|
| **Confirmation bias** | Seeing only what supports the existing judgment | Do the decision-maker's public statements cite reporting selectively? |
| **Anchoring** | Locked to the first information received | Has an early erroneous assessment been carried forward unchanged? |
| **Mirror-imaging** | Assuming the other side is rational in the same way you are | Are options being ruled out on "I wouldn't do that in their place"? |
| **Historical-analogy trap** | Forcing past experience onto the current situation | Is "the same thing as last time" being used as an analogy while the differences go unexamined? |

### 3. Organisational inertia
- Bureaucracies tend to continue what they already do
- Military institutions prefer proven options
- Check for institutional factors that systematically favour certain options

### 4. Domestic political constraints
- Public opinion, electoral timetables, factional interests
- Which options are domestically too costly?
- Which options score domestic points?

## Probability adjustment template

```
Actor: []
Available options: [from SKILL-05]

[PROBABILITY ADJUSTMENT]
Option A:
  Historical preference: [high/medium/low]
  Effect of cognitive bias: [note]
  Organisational inertia: [favours/impedes]
  Domestic politics: [favours/impedes]
  → Combined probability label: [high/medium/low/very low]

Option B: (as above)
```

## Output format

```
Actor: []
Available options: [from SKILL-05]

Option A → probability: [high/medium/low/very low]  Basis: []
Option B → probability: [high/medium/low/very low]  Basis: []
Option C → probability: [high/medium/low/very low]  Basis: []
```

## Cautions
- ⚠️ Adjusting probability is **not the same as ruling an option out** — "very low" must still be listed
- ⚠️ When the actor is judged to be under **high pressure and in the loss domain**, the probability ordering must switch to "maximise tail potential for reversing the loss" (Discipline 12, Prospect Theory)
- ⚠️ When the adversary is an authoritarian system, run the **adversary cognitive-distortion correction** first (Discipline 15, see SKILL-04) — what you are forecasting is their choice given a distorted picture of reality
- ✅ Next: **SKILL-08** (second-order & cascading effects)
- 💡 Probability labels are used formally in SKILL-09 scenario forecasting, so each must have a stated basis
