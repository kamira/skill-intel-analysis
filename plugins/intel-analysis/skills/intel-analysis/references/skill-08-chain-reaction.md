# SKILL-08|Second-order & cascading effects

> 語言 / Language: [繁體中文](skill-08-chain-reaction.zh-tw.md) · **English**

## Overview
Work through the action → reaction → counter-action chain, assess escalation and de-escalation
paths, and use the cross-domain transmission matrix to manage simultaneous multi-domain
transmission and feedback loops.

## Framework position
**Step 7 + systemic layer B**|Ten-step analytic framework

## Core question
> How does the board change after the move? What is the action → reaction → counter-action chain?

## Governing principle
> Analysis is not a static snapshot. Once A plays X the whole board changes — B reacts, C adjusts,
> and even A's own next options are different.
> **Analysis that ignores feedback loops is chess played in a vacuum.**

## Procedure

**1. Action → reaction chain**
- If A plays a given card, how do B's options change?
- How does B's reaction propagate to C?

**2. Escalation and de-escalation paths**
- Under what conditions does the situation spiral upward?
- Under what conditions does it stabilise or cool?

**3. Cross-domain transmission**
- How does military action spill into the economic domain?
- How do economic sanctions constrain political decision space?
- How do information operations change the political authorisation for military action?

**4. Feedback correction**
- How does the cascade change decision-makers' cognitive frames and risk appetite?
- How does it reshape the hard constraints (making an unavailable option available, or the reverse)?

## Systemic layer B: the cross-domain transmission matrix

When an event fires in several domains at once, use the transmission matrix to manage
simultaneous multi-domain propagation.

**Structure**: actors on the horizontal axis, transmission domains (military, economic, political,
information) on the vertical.

**Procedure**:
1. Fill the diagonal first: each actor's direct action in the domain it leads
2. Then fill the off-diagonal cells: how that action transmits into other domains
3. Mark the feedback loops: which transmissions loop back onto the originating actor

```
Transmission matrix (example layout)

           │ Military │ Economic │ Political│ Info
───────────┼──────────┼──────────┼──────────┼──────────
Actor A    │ [direct] │ [transm.]│ [transm.]│ [transm.]
Actor B    │ [transm.]│ [direct] │ [transm.]│ [transm.]
Actor C    │ [transm.]│ [transm.]│ [direct] │ [transm.]
```

## Cascade template

```
Initial action: [actor A plays option X]

[FIRST-ROUND REACTIONS]
Actor B: [reaction] → change to B's available options: []
Actor C: [reaction] → change to C's available options: []

[ESCALATION PATH]
Trigger conditions: []
Escalates to: [next intensity level]

[DE-ESCALATION PATH]
Trigger conditions: []
Settles at: [description of the stable state]

[CROSS-DOMAIN TRANSMISSION]
Military → economic: []
Economic → political: []

[FEEDBACK CORRECTION]

```

## Output format

```
Initial action: [actor A plays option X]
Reaction chain: [B reacts] → [C reacts]
Escalation path: trigger [] → escalates to []
De-escalation path: trigger [] → settles at []
Cross-domain transmission: [principal transmission path]
Feedback correction: [constraints reshaped / preferences reinforced]
```

## Devil's Advocacy (adversary advocate)

In every cascade analysis, at least one key actor must be worked through as Devil's Advocacy, so
that you do not think for the adversary in your own logic.

### Governing principle
> **Not "what would I do if I were the adversary", but "what would I do holding the adversary's
> information, interests, constraints and cognitive biases".**
> The first is still mirror-imaging. Only the second is genuine adversary simulation.

### Procedure

**1. Choose whom to advocate for**
- Choose the actor **most likely to be misjudged** in this analysis (usually the adversary, or whoever's interests differ most from the analyst's)
- Every cascade analysis works through at least one actor this way

**2. Switch the information environment**
Answer the following from the adversary's position:
```
What I (as [actor]) know at this moment:
- Confirmed facts (what the adversary's own collection can see): []
- What I do not know (information the adversary may lack): []
- What I may be getting wrong (mistaken beliefs the adversary may hold): []
```

**3. Switch the interest and constraint frame**
```
My (as [actor]) ranked core interests:
1. [from the SKILL-04 actor card, re-ranked from the adversary's viewpoint]
2. []
3. []

The constraints I face (seen from inside):
- Domestic politics: []
- Resources and capability: []
- Organisational inertia: []
- Time pressure: []
```

**4. Switch the cognitive frame**
```
The cognitive biases I (as [actor]) am most likely to hold:
- Historical analogy: which past experience am I most likely to read the present through? []
- Confirmation bias: what am I most inclined to believe? []
- View of the opponent: what do I think the opponent will most likely do, and why? []
```

**5. Decide as the adversary**
```
Given that information, those interests, those constraints and that cognitive frame,
my (as [actor]) most likely next move is: []

Because: []

How this differs from the adversary behaviour forecast from the analyst's viewpoint: []
The difference comes from: [information gap / interest gap / cognitive gap]
```

### Devil's Advocacy output format

```
[DEVIL'S ADVOCACY]
Actor advocated for: []
Information-environment difference: [what the adversary knows, does not know, may misjudge]
Ranked interests (adversary's view): []
Cognitive frame: [historical analogy / confirmation bias / view of the opponent]
Adversary's most likely action: []
Divergence from the analyst's forecast: []
Source of the divergence: []
Effect on the analysis: [whether it changes the path or probability of the cascade]
```

### When it is mandatory
- Whenever the judgment "the adversary could not possibly do that" appears → **mandatory**, because that is exactly when mirror-imaging is most dangerous
- Whenever the adversary's behaviour is "unexpected" (the SKILL-06 consistency check fails) → **mandatory**
- Whenever the adversary's domestic political or factional pressures are opaque → **recommended**

### When it may be omitted
- When the adversary's behaviour is highly consistent with its interest logic and well supported by observable evidence

## Cautions
- ⚠️ Where one cross-domain transmission path is unusually strong, foreground it in SKILL-09 and SKILL-10
- ✅ Next: **SKILL-09** (scenario forecasting)
- 💡 Feedback loops can change the SKILL-05 board; go back and update it when needed
- 💡 Run **Devil's Advocacy** on at least one key actor in every cascade analysis, to keep mirror-imaging out
