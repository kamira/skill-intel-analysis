# SKILL-01|Problem definition & scoping

> 語言 / Language: [繁體中文](skill-01-problem-definition.zh-tw.md) · **English**

## Overview
Define the analytic question, the time horizon and the boundaries of the issue, setting a firm
analytic footing for every step that follows.

## Framework position
**Step 1**|Ten-step analytic framework

## Core question
> What question is this analysis answering?

## Governing principle
> **When the question is unclear, do not broaden it on your own — clarify first, then analyse.**
> This step fixes the boundaries of everything downstream: the more precise the definition, the
> firmer the later steps. A vague question yields only a vague judgment.

## Procedure

**1. State the analytic question in one sentence**
- Avoid vague formulations ("analyse the situation" → "will X take action Z within window Y?")
- If the question is unclear, **check with the requester first; do not broaden it yourself**

**2. Set the time horizon**
- Short term: within days
- Medium term: weeks to months
- Long term: beyond three months

**3. Bound the geography and the issue**
- Which countries and actors are in play
- Which domains are involved (military / economic / political / information)
- What is explicitly out of scope for this analysis

## Output format

```
Analytic question: [one sentence]
Time horizon: [short / medium / long, stated concretely]
Geographic scope: [countries / regions]
Issue scope: [domains involved]
Out of scope: [aspects this analysis does not address]
```

## Cautions
- ⚠️ When the question is unclear, **do not assume a scope** and press on — clarify first
- ⚠️ This step fixes the boundaries of every later step; precision here pays off downstream
