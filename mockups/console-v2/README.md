# console-v2 — 事件鍊與國家背景基準的版面提案（mockup）

> **這是 mockup，不是上線頁面。** 產出的 HTML 一律帶 `noindex`。
> 每一頁的頂端有橘色橫幅標明這件事。

視覺語言取自 [`kamira/intel-analysis-showcase`](https://github.com/kamira/intel-analysis-showcase)
的 `assets/css/declaration.css`（色票、字級、間距、`dcl-` 類別命名），
以便兩個站看起來是同一套系統。本次新增的類別一律 `mk-` 前綴。

## 為什麼有這一版

目前上線的 `site/index.html` 是單頁應用，四個分頁都在同一份文件裡。
其中兩頁的**內容是錯的**，而且不是排版問題：

### 1. 「事件鍊」這個詞被用在錯的東西上

`site/` 把**版本鏈快照**（同一個命題的逐版修訂）叫作「事件鍊」。
於是總表裡每一列看起來都像一條因果鍊，實際上只是一句話的修訂史；
而事件與事件之間的關係——一則新聞同時推動好幾種後果——在整個站台裡沒有位置。

這一版把「事件鍊」還原成它該有的意思：

> **一個主要事件，底下掛著會改變後果機率的新聞。**

`events/us-iran/` 是完整的一頁：美伊衝突（2026-06-09 → 07-12），
4 種後果分支、9 則新聞，**4 條機率曲線畫在同一組座標上**。
分開畫會看不見唯一重要的那件事——同一天，談和往下、互擊往上。

7/09「美恢復打擊伊朗、停火結束」當天：談和 45% → 25%、互擊 65% → 80%。
7/11「停火再宣結束仍續談」當天：談和回到 45%、互擊回落到 60%。

### 2. 「國家背景基準」寫著一句不成立的話

`site/index.html` 這一頁的頁尾寫著：

> 核心利益、利益排序、紅線這三個 SKILL-04 欄位**不存在於預測驗證資料庫**，
> 因此本頁不呈現，也不從命題臆測。

對預測驗證資料庫，這句是真的。對這套方法論，這句是假的——
這些欄位一直都在，只是在另一個地方：Notion 的**「各國立場」**（11 張利益卡片）。
舊版拿它算不出來的東西當成不存在，於是頁面實際呈現的是關鍵詞計數，
卻掛著「國家背景基準」這個名字。

這一版直接呈現真正的卡片（八節：核心利益／結構性限制／國內政治與治理約束／
對外政策與常用手段／時局分析／軍事分析／經濟分析／反證訊號），
並把**每張卡片的完整度畫在卡面上**。

伊朗只有 8 節裡的 1 節——它是最大事件鍊的當事方，卻是所有卡片裡最薄的一張。
這件事必須在畫面上看得出來。

### 3. 不再是單頁式

每一個區段是自己的文件、自己的網址，跨頁互連（事件鍊 ↔ 利益卡片），
與 showcase 的 `/chains/`、`/chains/<id>/`、`/declaration/` 同一種結構。

## 重新產生

```
node mockups/console-v2/build.js
```

`build.js` 讀 `site/data.js` + `events.json` + `actors.json`，輸出 HTML。
改內容改 JSON，不改版面碼。

## 上站前必須先決定的事

**利益卡片不在目前已核定的公開範圍內。**

CHG-20260828-02 當時的使用者決定是「公開範圍：(a) 事件鍊摘要與機率」，
來源限定在預測驗證資料庫。「各國立場」是另一個資料源，逐段是分析者自己寫的
長期研判（含對特定國家領導人政治動機的判斷），不是帳本欄位。

把它上站等於擴大公開範圍，**需要一次新的使用者決定**，不能靠這張 mockup 順帶帶過去。
本目錄的產出一律 `noindex`，並且沒有接上 `.github/workflows/pages.yml`。

新聞標題同理：它們來自每日國際觀點，該資料源在 CHG-20260828-02 是「整批排除」的。
本 mockup 只用當日頁的**標題**、不用正文，但這仍是一次範圍變更。
