## 為什麼不回填歷史引用

這一項值得單獨寫,因為直覺會想去改。

ACC-20260828-01 第 1 條的證據是「瀏覽器實際開啟 `mockups/intel-console/index.html`,
四個導覽項逐一切換皆出畫面」。檔案刪掉後,那行路徑指向不存在的東西。

**但那句話沒有變成假的。** 它記錄的是 2026-08-28 當下發生過的事,而當下那個檔案存在。
如果把它改成指向 `site/` 或加註「已刪除」,ACC 就從**時間點的證言**退化成**現況索引**——
而現況索引是 `git ls-files` 的工作,不是 ACC 的。

一份會隨現況被改寫的驗收紀錄,等於沒有驗收紀錄。

## 誠實的邊界

- 本張只驗「刪除沒有弄壞任何東西」,不重驗 `site/` 站台(那是 ACC-20260828-02 的射程,
  且本次改動未觸及 `site/`)。
- `git grep` 只掃工作區當前內容;若有以動態字串組出該路徑的程式碼(例如拼接
  `"mock"+"ups/"`),搜尋抓不到。本 repo 的程式碼只有 python 治理腳本與靜態 HTML,
  沒有這類寫法,但這個限制如實列出。
